Privacy Policy

Effective Date: [EFFECTIVE DATE]

1. Overview and Commitment

This Privacy Policy describes how [ENTITY NAME] ("we", "us", or "our") processes information when you interact with the Label Audit web application and API. We prioritize user privacy and operate with a minimal data footprint.

2. Audio and File Processing

When you upload an audio file for analysis:

  • The file is temporarily stored in a local directory solely to allow feature extraction and model inference.
  • The temporary file is deleted in a protected code block immediately after inference finishes, even if processing fails.
  • We do not retain permanent copies of your audio files, nor do we use uploaded audio to train future models.

3. Server Logging Practices

To maintain system stability and enforce rate limiting, our servers log:

  • A unique pseudorandom Request ID
  • Processing duration in milliseconds
  • HTTP response status codes
  • Client IP address (used solely in-memory to prevent denial of service and enforce rate limits)

We never log: Audio content, song titles, artist names, or lyrics text in server logs.

4. External Services and Third Parties

If you specify a song title and artist for automatic lyrics retrieval, the system queries public databases (specifically LRCLIB or Genius API if configured). Only the title and artist strings are transmitted; audio files are never sent to third-party endpoints.

If a hosted Large Language Model provider is configured by the server administrator, structured summary numbers (such as valence and arousal values) may be processed to generate explanatory notes.

5. No Accounts, Cookies, or Trackers

Label Audit does not require user accounts. We do not use advertising trackers, profiling cookies, or commercial analytics scripts.
